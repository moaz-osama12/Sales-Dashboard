📊 Sales Dashboard - Excel Project

🚀 Project Overview

This project presents an interactive **Sales Dashboard built using Microsoft Excel**, designed to analyze sales performance and generate actionable business insights.

The dashboard transforms raw data into a clear and visually engaging format to support decision-making.

---

🔍 Key Features

* 📈 Total Sales, Profit, Quantity & Profit Margin (KPIs)
* 🗂️ Performance by Category & Sub-Category
* 📅 Monthly trends & seasonality analysis
* 🌍 Regional performance visualization
* 🏆 Top & Bottom performing products

---

💡 Key Insights

* Technology is the most profitable category
* Some products generate high sales but low profit → optimization opportunity
* Sales show a consistent growth trend over time

---

🛠️ Tools & Skills Used

* Microsoft Excel
* Data Cleaning & Transformation
* Pivot Tables
* Advanced Charts
* Dashboard Design
* KPI Tracking

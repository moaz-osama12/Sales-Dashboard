# Sales-Dashboard
# 📊 Sales Analysis Dashboard (Excel)

📌 Overview

This project presents a comprehensive **Sales Analysis Dashboard** built using Microsoft Excel.
The goal is to analyze sales performance, identify trends, and support data-driven decision-making.

---

🎯 Objectives

* Analyze total sales, profit, and quantity
* Identify top-performing categories and products
* Evaluate profit margins and discount impact
* Understand customer distribution across regions
* Track performance over time (quarters & years)

---

🛠️ Tools & Techniques

* Microsoft Excel
* Pivot Tables & Pivot Charts
* Slicers for interactive filtering
* Data Cleaning & Transformation
* KPI Design & Visualization

---

📈 Key Insights

* Technology category generates the highest sales
* Office Supplies contribute significantly to quantity sold
* Some sub-categories show negative profit, indicating potential losses
* Sales performance varies across regions, with certain states dominating

---
📊 Dashboard Features

* KPI Cards (Total Sales, Profit, Quantity, Profit Margin)
* Category-wise breakdown (Sales, Profit, Quantity)
* Sub-category performance analysis
* Top & Bottom products by sales
* Geographic distribution of customers
* Interactive filters (Category, Year, Quarter)

---

📂 Dataset

* Sample sales dataset (cleaned and structured for analysis)
* Includes fields such as:

  * Sales
  * Profit
  * Quantity
  * Category / Sub-category
  * Region / State
  * Order Date

---

🚀 How to Use

1. Open the Excel file
2. Use slicers to filter by category, year, or quarter
3. Explore visuals to gain insights

---

💡 Conclusion

This dashboard helps uncover actionable insights and provides a clear view of business performance using simple yet powerful Excel tools.
